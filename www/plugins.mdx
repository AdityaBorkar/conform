# Plugins

One file per plugin in `src/plugins/*.ts`, exported from `src/plugins/index.ts:1`. Each plugin is created with `definePlugin` (`src/api/plugin.ts:151`) and owns its rules via `Plugin#defineRule` (`src/api/plugin.ts:69`).

All filesystem access goes through `Target` (`src/utils/fs.ts:10`): `fileExists`, `readFile`, `readJson` (JSON with `//`/`/* */` comment stripping), `packageJson`.

Domains `DOMAIN` (`src/plugins/utils/domain.ts:1`): `BUILD` ("Build & Tasks"), `CODE_QUALITY` ("Code Quality"), `STYLE` ("Style & Validation"), `DEV_ENVIRONMENT` ("Dev Environment"), `DOCUMENTATION` ("Documentation"), `GITHUB_CONFIG` ("GitHub Configuration"), `SECURITY` ("Security & Governance"), `OBSERVABILITY` ("Observability"), `TESTING` ("Testing").

Param schemas use `arktype` `type(...)`. Violations → `Status.fail("Invalid params: …")` without calling `test` (`src/api/plugin.ts:12`).

Override syntax for every rule: `RuleLevel` string (`off | warn | error`, `error → fail`) or flat `{ level?, ...params }` with `level` optional, no `params` wrapper. See [Configuration](/configuration).

`src/plugins/package_json.ts:44` — `id: "package-json"`, context `{ fileExists, packageJson }`.

| Rule | Params | Defaults | Severity | Description |
|---|---|---|---|---|

| `no-prepublish` | `{ scripts: string[] }` | `["prepublish"]` | fail | Deprecated `prepublish` script not used. |

  "package-json/entry-point": { fields: ["exports"] },

## Adding a plugin to a config

```ts title="conform.config.ts"
import { defineConfig } from "@adistack/conform";
import { myPlugin } from "./my-plugin.ts";

export default defineConfig({
  preset: "package",
  plugins: [myPlugin],
  rules: { "my-plugin/my-rule": "error" }
});
```
