# API

## Imports

Import everything from the package root. Deep imports are not needed:

```ts
import { check, defineConfig, defineMonorepoConfig } from "@adistack/conform";
import { definePlugin, definePreset, Status, DOMAIN } from "@adistack/conform";
import type { Target } from "@adistack/conform";
```

Built-in plugins have a second entry point:

```ts
import { biome, husky } from "@adistack/conform/plugins";
```

The `@/*` alias maps to `./src/*`.

## Run a check

```ts
import { check } from "@adistack/conform";

const result = await check("/path/to/repo", { verbose: true });

if ("code" in result) {
  console.error(result.code, result.message); // no-config, preset-not-found, …
} else if ("packageResults" in result) {
  console.log(result.summary); // monorepo result
} else {
  console.log(result.output.summary, result.hasFail); // single-package result
}
```

Options are `{ verbose?, json?, groupBy?: "domains" | "files" }`.

## Define configs

```ts
defineConfig({ preset: "package" });                 // single-package repo
defineMonorepoConfig({ ".": { preset: "package" } }); // monorepo
```

Both helpers only provide typing. They perform no runtime transformation.

## Define checks

```ts
definePlugin({ id: "x", context: (t: Target) => ({}) });              // create a plugin
definePreset([myPlugin] as const)({ name: "x", description: "y" });   // create a preset
Status.pass(); Status.warn("later"); Status.fail("now");              // return a verdict
DOMAIN.BUILD; // "Build & Tasks". Also STYLE, DEV_ENVIRONMENT, and more.
```

## Read files

```ts
new Target(path);
target.fileExists("biome.json");  // boolean
target.readFile("README.md");     // string | null
target.readJson("tsconfig.json"); // parsed object | null, comments allowed
target.packageJson();             // package.json contents | null
```

## Types

```ts
type Severity = "pass" | "warn" | "fail";
type RuleLevel = "warn" | "off" | "error"; // error becomes fail
type RuleConfig<P> = RuleLevel | ({ level?: RuleLevel } & Partial<P>);
interface RuleResult { id: string; domain: string; files: string[]; description: string; status: Severity; message?: string; }
interface ConformConfig { preset: string; plugins?: Plugin[]; rules?: StrictRuleOverrides; }
interface ConformOutput { preset: string; path: string; results: RuleResult[]; summary: { pass: number; warn: number; fail: number }; }
```

Use `isConformanceError(x)` and `isMonorepoConformanceResult(x)` to narrow result types.

Agent hint: the engine lives in `src/api/engine.ts`, the plugin base in `src/api/plugin.ts`, presets in `src/api/preset.ts`, and shared types in `src/types.ts`.
