# @adistack/conform

Conform checks your repository against a Preset and reports drift. It does not fix anything. You fix what it reports.

```sh
bun add -d @adistack/conform
bunx conform check
```

```ts title="conform.config.ts"
import { defineConfig } from "@adistack/conform";

export default defineConfig({ preset: "package" });
```

## Core ideas

- **Preset is a list of checks.** It is code, not YAML.
- **Rule is a single check.** Each rule has exactly one job.
- **Drift means the repo does not match the Preset.** Drift is any `warn` or `fail` result.
- **Conform only reports.** It never scaffolds or auto-fixes.

## Requirements

- Bun is required. Node is not supported.
- One config file is required: `conform.config.ts` at the repo root.
