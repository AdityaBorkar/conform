# Quick Start

## 1. Install

Conform requires Bun. Node is not supported.

```sh
bun add -d @adistack/conform
```

Verify the installation:

```sh
bunx conform --version
```

## 2. Create a config

Create one file at the repository root named `conform.config.ts`:

```ts title="conform.config.ts"
import { defineConfig } from "@adistack/conform";

export default defineConfig({ preset: "package" });
```

If your repository contains multiple packages, use a monorepo config instead. See [Monorepo](/monorepo).

## 3. Run a check

```sh
bunx conform check                # check the current directory
bunx conform check -v             # also show passing checks
bunx conform check --json         # print machine-readable JSON
bunx conform check --path ./other # check a different directory
```

## 4. Read the output

- `✓` means pass.
- `⚠` means warn. Fix it later. The exit code is 2.
- `✗` means fail. Fix it now. The exit code is 1.

```
@adistack/conform — package preset

Build & Tasks
  
    ✓ package-json/required-fields   all required fields present
    ✗ package-json/entry-point       no main, module, or exports field defined

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  59 passed · 2 warned · 1 failed
```

The summary always counts every result. The `-v` flag only controls which rows are displayed. Rule IDs are always full `plugin-id/rule-id` paths.

## 5. Tune noisy rules

If a rule does not fit your repository, soften it or turn it off:

```ts title="conform.config.ts"
import { defineConfig } from "@adistack/conform";

export default defineConfig({
  preset: "package",
  rules: {
    "biome/format-script": "warn", // soften a failure into a warning
    "github/dependabot": "off",    // skip the rule entirely
  },
});
```

All tuning options are described in [Configuration](/configuration).

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `No conform.config.ts found` | The config file is missing | Create `conform.config.ts` |
| `Preset 'x' not found` | The preset name is wrong | Use `package` or add `src/presets/x.ts` |
| `--group is not supported with --json` | The flags are mutually exclusive | Remove `--group` when using `--json` |
| `Invalid severity "…"` | The `level` value has a typo | Use only `off`, `warn`, or `error` |
| Crash under Node | The wrong runtime is used | Run with Bun |
