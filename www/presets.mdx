## `package`

> Conformance rules for publishing an NPM package.

Plugins (in order): `packageJson`, `biome`, `tsconfig_json`, `husky`, `docs`, `gitignore`, `github`, `zed`, `bun`.

Shipped overrides (`src/presets/package.ts:25`):

```ts
rules: {
  "gitignore/excludes":           { file_expressions: ["node_modules", ".env*", "*.env", "*.gen.ts"] },
  "husky/hook":                   { hooks: [
    { file: ".husky/pre-commit", contains: "bun run format" },
    { file: ".husky/commit-msg", contains: 'bun commitlint --edit "$1"' },
  ]},
  "package-json/required-fields": { fields: ["license","name","author","contributors","repository","publishConfig","homepage","files","bugs","description","keywords","engines"] },
}
```

Config `rules` shallow-merge over these per rule ID.

### Using the preset

```ts title="conform.config.ts"
import { defineConfig } from "@adistack/conform";

export default defineConfig({
  preset: "package",
  rules: {
    "github/dependabot": "off",                       // not needed
    "biome/format-script": "warn",                    // soften
    "package-json/required-fields": {                 // extend required fields
      fields: ["license", "name", "author", "engines"]
    }
  }
});
```

## Authoring a custom preset

See [Authoring](/authoring) for `definePreset` (curried + object form) and `PresetWithPlugins<Ps>` typing. In brief:

```ts title="src/presets/acme.ts"
import { definePreset } from "@adistack/conform";
import { biome } from "@/plugins/biome.ts";
import { husky } from "@/plugins/husky.ts";

export default definePreset([biome, husky] as const)({
  name: "acme",
  description: "Acme org defaults",
  rules: {
    "biome/dev-deps": "error",
    "husky/hook": { hooks: [{ file: ".husky/pre-commit", contains: "bun run format" }] }
  }
});
```

Referenced as `preset: "acme"` in `conform.config.ts`.
