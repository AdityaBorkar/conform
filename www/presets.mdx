# Presets

Conform ships with one built-in preset: `package`. It checks everything an npm package needs.

```ts title="conform.config.ts"
import { defineConfig } from "@adistack/conform";

export default defineConfig({ preset: "package" });
```

## The `package` preset

The preset contains 9 plugins and 62 rules. It pre-tunes 7 rules (`biome/config`, `bun/bunfig-content`, `gitignore/excludes`, `husky/hook`, `package-json/required-fields`, `typescript/compiler-options`, and `zed/settings`). Your `rules` in `conform.config.ts` override these defaults per rule ID.

## Tune the preset

```ts
export default defineConfig({
  preset: "package",
  rules: {
    "github/dependabot": "off",
    "biome/format-script": "warn",
  },
});
```

To build your own preset, see [Authoring](/authoring).

## GitHub token

Many `github/*` rules call the GitHub API. They require a token:

```sh
export CONFORM_GITHUB_API_TOKEN="ghp_..."
```

Without a token, those rules fail. Either set the token or disable the rules you do not need.
