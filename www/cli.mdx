# CLI

## Synopsis

```sh
conform check [--path <dir>] [--json] [-v] [--group domains|files]
```

| Flag | Default | Meaning |
|---|---|---|
| `--path <dir>` | Current directory | The repository directory to check. |
| `--json` | Off | Print machine-readable JSON. Cannot be combined with `--group`. |
| `-v, --verbose` | Off | Show passing checks in addition to warnings and failures. |
| `--group <mode>` | `domains` | Group output by `domains` or `files`. Unknown values fall through to `domains`. |
| `--version` | — | Print the Conform version. |

```sh
bunx conform check                      # check the current directory
bunx conform check --path ./my-project  # check a different directory
bunx conform check -v --group files     # show everything, grouped by file
bunx conform check --json > out.json    # save JSON output for CI
```

Combining `--json` with `--group` is an error and exits with code 1.

## Human output (default)

The terminal output groups results by domain, then by file. Rule IDs are always full `plugin-id/rule-id` paths:

```
@adistack/conform — package preset

Build & Tasks
  
    ✓ package-json/required-fields   all required fields present
    ✗ package-json/entry-point       no main, module, or exports field defined

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  59 passed · 2 warned · 1 failed
```

Without `-v`, passing rows are hidden. The summary still counts every result.

## Machine output (`--json`)

```json
{
  "preset": "package",
  "path": "/abs/path",
  "results": [{ "id": "package-json/entry-point", "status": "fail", "message": "…" }],
  "summary": { "pass": 59, "warn": 2, "fail": 1 }
}
```

- `results` contains only the visible rows. Pass `-v` to include passing checks.
- `summary` always counts every result, before filtering.
- Monorepo JSON contains an `outputs[]` array with one entry per package. See [Monorepo](/monorepo).

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Every rule passed. |
| `1` | At least one rule failed, or the flags were misused. |
| `2` | Only warnings, or `no-config`, `preset-not-found`, or monorepo errors. |

Use the exit code directly in scripts and CI:

```sh
bunx conform check || echo "drift detected (exit $?)"
bunx conform check --json | jq '.summary'
```
